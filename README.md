# Four Seasons Restaurant — Google Maps Showcase

Responsive single-page website for Four Seasons Restaurant in Kankarbagh, Patna.

## Features
- Restaurant overview and photo gallery
- Sample food menu with category filters
- Responsive mobile navigation
- Table reservation, takeaway and menu enquiries via WhatsApp
- Embedded Google Map and direct directions link
- Restaurant metadata for search engines

## Before publishing
- Verify the business address and phone number with the owner.
- Replace sample menu items and prices with the current menu.
- Replace illustrative AI-generated images with owner-approved restaurant photos.
- Verify opening hours and available services.
- The WhatsApp form sends an enquiry only; it does not confirm bookings or orders or accept payments.

## Deploy
Deploy the complete repository to Netlify or Vercel. Keep the `assets/` directory alongside `index.html`. Add the published website URL to the restaurant owner's Google Business Profile Website field.
